# Revisión de accesibilidad y casos límite (F10, T080 y T081)

Fecha: 2026-11-14. Compilación de producción local con la CSP de producción y una API simulada con datos ficticios;
Chrome sin interfaz controlado por el protocolo de depuración (teclado real por eventos de entrada, árbol de
accesibilidad del navegador, emulación de medios). Los resultados que exigen un lector de pantalla real **no se han
obtenido** y quedan pendientes del autor (ver el final).

## T080 — teclado y árbol de accesibilidad

Pantallas: login, Workflows, editor, Ejecuciones, detalle de ejecución, Aprobaciones, Conexiones, Miembros y Cuenta.

| Comprobación                                                                                                | Resultado                                                                                                                                                                                                                                                                                                              |
| ----------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

En las estaciones el anillo doble va sobre el círculo (`:focus-visible` del nodo, `station.css`)                                                                                                                                                                                                               |

| Landmarks                                                                                                   | `banner`, `navigation «Navegación principal»`, `main` único; en el editor `complementary «Paleta de nodos»`, `complementary «Panel lateral»`, `region «Problemas»`; en Ejecuciones `region «Filtros»`; en el detalle `complementary «Detalle del nodo»`.
